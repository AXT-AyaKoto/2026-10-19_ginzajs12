# 『JavaScriptで競技プログラミングをする』

[Ginza.js #12](https://ginzajs.connpass.com/event/404171/)にて綾坂ことが行ったショートセッション『JavaScriptで競技プログラミングをする』のスライドと検証スクリプト群です。

## スライドをもう一度見たい方へ

### PDFだけ見れれば良い方へ

右側にGitHub Releasesありますね？そこのAssetsにPDFあるのでどうぞ

### スライド動かしたい方へ

[AyaExpTech Presen'it!](https://github.com/AXT-Studio/presen-it)を使っています。

```sh
pnpm install
pnpm exec presenit dev presentation # Dev server
pnpm exec presenit export presentation # PDF export
pnpm exec presenit build presentation # HTML export
```
